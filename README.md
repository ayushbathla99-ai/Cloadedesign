# Cloadedesign

This repository hosts the [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) skill bundle for Claude Code, alongside other project content.

## Installed skills (`.claude/skills/`)

- `ui-ux-pro-max` — design intelligence database (UI styles, color palettes, font pairings, UX guidelines, charts) across 17 tech stacks
- `ui-styling` — Tailwind/shadcn theming utilities and canvas fonts
- `design` — logo, icon, CIP, and social asset design guidance
- `design-system` — design tokens and component specs
- `brand` — brand guidelines, voice, and asset management
- `slides` — slide deck layout and copywriting
- `banner-design` — banner sizing and style references

See `LICENSE` (MIT) for the skill bundle license; `.claude/skills/ui-styling/LICENSE.txt` (Apache 2.0) covers the bundled canvas fonts.
